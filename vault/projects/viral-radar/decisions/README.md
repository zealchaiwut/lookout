# Decisions (viral-radar)

Human-authored ADR-lite files live in this folder. The readable timeline is
[[projects/viral-radar/decisions-view|Decisions Hub]].

Copy `TEMPLATE.md` or run:

```bash
bin/lookout decide viral-radar --title "..." --issue 115 --sprint sprint-14
```

Status: `proposed` → `active` → `superseded` | `reverted`.
Never delete a decision file — flip status and link the successor.
