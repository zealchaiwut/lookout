# Journal

The journal is **fleet-wide** — personal notes that can mention any project —
which is why it sits under **Fleet** in the sidebar, next to Ideas, not inside
a single project.

Source path: `sources.journal_entries` in `targets.yaml` (`~/dev/journal/entries`).
Entries are collected by `journal_delta.py`; that collector is not yet wired
into the nightly `bin/lookout` run, so this page stays a pointer until it is.
